# Hold On, Mars! Keep the Crew Safe

**NASA Space Apps Challenge 2026 · Challenge: "Build a Junior Astronaut Mission Trainer" · Team Holland Pilots**

▶️ **Play on Roblox: https://www.roblox.com/games/99201616522797**
(free; playing needs a free Roblox account. Cross-platform.)

Hold On, Mars! is a first-person co-op survival game on Roblox. It is designed for ages 7–12, but anyone can play. The players are the crew of a Mars base. Together they keep water, food and oxygen running until the launch window opens on sol 5 and the rocket can take them home. If they miss it, the crew has to hold on longer. Every choice costs time, water or safety. If the crew runs out, nobody gets hurt: the mission stops, the game explains what went wrong, and the crew can try again.

## The mission: five sols, five lessons

| Sol | Lesson | What the crew does |
|---|---|---|
| 1. Landing | Everything we need must be found on Mars | Put on a space suit, go outside, collect rock samples, sort them into iron, nickel and manganese |
| 2. Dust and power | Dust blocks sunlight, plants grow slowly | Clean dusty solar panels after a dust storm, fix the water pump by soldering its circuit board, plant crops |
| 3. Water from ice | Water is hidden as ice under the ground | Build an ice drill from the metals, dig ice where NASA's ice map shows it, take shelter from a solar storm |
| 4. Things break | Machines fail, repairs cost time | Repair the radar after a marsquake, fix the oxygen generator, harvest crops |
| 5. The launch window | Planets must line up to fly home | Tell Earth the crew is ready, collect 10 rock samples in total, launch the rocket |

## Real NASA data in the game

Every value shows its source and a **LIVE** or **ARCHIVED** label with the real date. The server asks the live APIs once at start; if a request fails, it uses a saved snapshot from [`src/server/data/`](src/server/data/).

| Data | Source | In the game |
|---|---|---|
| Solar flares (FLR) | [NASA DONKI](https://ccmc.gsfc.nasa.gov/DONKI/api/), NASA CCMC | A real flare becomes the solar storm; the crew must take shelter |
| CME forecast for Mars | NASA DONKI WSA-ENLIL | Warning card, labelled as a model forecast |
| Earth–Mars light time | [NASA JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) | Mission Control's answers through Sparky arrive after today's real signal delay |
| Mars surface dose rate | Curiosity RAD via [NASA OSDR RadLab](https://visualization.osdr.nasa.gov/radlab/gui/data-api/) | Personal radiation dose meter, faster during a solar storm |
| Mars weather | Curiosity REMS (CAB / NASA JPL-Caltech) | 2018 global dust storm and cold night cards |
| Water ice map | [NASA's Treasure Map for Water Ice on Mars](https://www.nasa.gov/solar-system/nasas-treasure-map-for-water-ice-on-mars/) (NASA/JPL-Caltech/ASU) | Science station map; the base is in Arcadia Planitia |
| Space crops | NASA Veggie and Advanced Plant Habitat (ISS) | Six real space crops grow at speeds based on their real days to harvest |
| Mars metals | NASA rover finds (Opportunity, Curiosity) | Iron meteorites, hematite and manganese rocks to collect and sort |

All facts and their sources are recorded in the team knowledge base: [`kb/data/`](kb/data/).

## How it is built

- **Roblox Studio + Luau** (typed, strict). The server owns all game state; clients only show it.
- **Rojo** syncs the code in [`src/`](src/) into Studio: `server` (simulation, events, NASA data), `client` (UI, mini-games), `shared` (config, mission plan, strings).
- Pure modules (mission rules, radiation model, solder joint) are tested headless with **Lune** in [`tests/`](tests/).
- **Selene** (lint) and **StyLua** (format) run before every commit.
- Sparky's chat uses Roblox **TextGenerator** with TextService filtering, an off-topic check, and a rule that any number in an answer must come from our checked fact list.

## Use of AI

The game idea and design are the team's own. AI coding assistants (Claude Code, OpenAI Codex, OpenCode) helped write and review code, data scripts and tests; every change was reviewed and tested by the team in Roblox Studio. The space suit glove 3D model was generated with Roblox Studio Assistant (noted in [`src/shared/Assets.luau`](src/shared/Assets.luau)). In the game, Mission Control's answers are generated by Roblox TextGenerator and marked as AI.

# For developers

## Quick start (Windows)

1. Install [Roblox Studio](https://create.roblox.com/) and sign in.
2. Install [Rokit](https://github.com/rojo-rbx/rokit/releases) (`rokit.exe self-install`), then in this folder:
   ```sh
   rokit install      # rojo, wally, selene, stylua, lune (pinned in rokit.toml)
   wally install      # Luau packages
   rojo plugin install
   rojo serve         # then press Connect in the Rojo plugin in Studio
   ```
3. Before committing: `selene src`, `stylua --check src`, `rojo build -o build.rbxl`.

Code lives in `src/` (`server`, `client`, `shared`). Project rules for people and AI agents: [`AGENTS.md`](AGENTS.md). Team knowledge base: [`kb/index.md`](kb/index.md).

## Codex + Roblox Studio (Windows)

1. In the Codex app, open this repository as a local project and trust it when prompted. Codex uses `AGENTS.md` for project instructions; it does not use the Claude `.mcp.json` configuration. Project MCP settings live in [`.codex/config.toml`](.codex/config.toml).
2. In Studio, open **Assistant → … → Manage MCP Servers**, enable **Studio as MCP server**, and turn on **ChatGPT (codex)** under **Quick connect**. This registers `Roblox_Studio` in your user-level Codex configuration; keep Studio open with the intended place loaded.
3. Install and register the shared knowledge base (requires `uv` on PATH; the first command downloads dependencies):
   ```powershell
   uv tool install basic-memory
   uv tool run basic-memory project add sol-sandbox "X:\Projects\NasaSpaceApps\kb" --local
   ```
   Replace the path with your checkout's absolute `kb` path. The project name must stay `sol-sandbox`. The repository's Codex configuration runs this server through `uv` directly, so `python -m uv` is not required.
4. Restart Codex or start a fresh session after configuration changes. Ask it: **“Read AGENTS.md and kb/index.md, then call list_roblox_studios. Do not change the place yet.”** A successful Studio tool call verifies the connection; the Quick connect toggle alone does not.

If a Basic Memory install was interrupted, repair it with `uv tool install --force basic-memory` before registering the project. Without Basic Memory, Codex can still read `kb/` directly and use `node scripts/kb.mjs`.

If Studio reports no clients, confirm the server is enabled in Codex's MCP settings and start a new session. If tools report authorization errors, restart Studio and Codex and re-enable Quick connect. Studio MCP shares requested game data with your AI provider; review Roblox's notice before enabling it.
