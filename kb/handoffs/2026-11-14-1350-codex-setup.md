# Handoff: Codex setup 2026-11-14 13:50

Конфігурацію Codex для репозиторію додано. Потрібно завершити встановлення Basic Memory та перевірити підключення до відкритого place з нового сеансу Codex.

## Done
- Додано `.codex/config.toml`: сервер `basic-memory` через `uv tool run`, проєкт `sol-sandbox`, UTF-8, тайм-аут запуску 120 секунд.
- У README додано інструкцію Codex + Studio, реєстрацію KB та перевірку через `list_roblox_studios`.
- Перевірено: глобальна конфігурація Codex уже містить `Roblox_Studio`, доданий Quick connect. Глобальний конфіг не змінювали.
- Виконуваний файл Studio MCP відповів на initialize і tools/list. Це не підтверджує доступ до конкретного place; у журналі були попередження 401 Unauthorized.

## Next
1. `uv tool install --force basic-memory`: попереднє встановлення зупинилося після тайм-ауту 120 секунд; `uv tool list` повідомляє про неповне встановлення. Повторний запуск із довшим тайм-аутом потребує згоди користувача.
2. `uv tool run basic-memory project add sol-sandbox "X:\Projects\NasaSpaceApps\kb" --local`.
3. Відкрити репозиторій у Codex, підтвердити довіру, почати новий сеанс і викликати `list_roblox_studios`; за помилки авторизації перезапустити Studio/Codex та Quick connect.

## Files touched
- `.codex/config.toml` — MCP для KB, без дублювання глобального Studio MCP.
- `README.md` — налаштування Codex і перевірка підключення.
- `kb/handoffs/2026-11-14-1350-codex-setup.md` — передача контексту.
