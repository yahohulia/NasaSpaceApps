# Materials and modules

Світ — це сітка клітинок (~200×110), кожна клітинка має матеріал. Гравець малює матеріали пензлем, гумка копає. Список нижче — пропозиція, на D-1 його зафіксують як контракт рушія.

## Природні матеріали
| Матеріал | Поведінка | Роль у грі |
|---|---|---|
| Реголіт | сиплеться як пісок | дешевий щит від радіації, але копати його коштує енергії |
| Базальт / камінь | твердий, не падає | природний дах; печера може стати укриттям |
| Лід | твердий, тане від нагрівача | єдине джерело води |
| Вода | тече | пиття, сировина для O₂, найкращий щит; поза модулем закипає або випаровується |
| O₂ | газ, розлітається | витікає крізь будь-яку дірку |
| CO₂ | газ (атмосфера Марса) | сировина для MOXIE і теплиці |
| Пил | осідає | лягає на панелі й знижує вироботку |

## Будівельні матеріали
| Матеріал | Поведінка |
|---|---|
| Стіна модуля | герметична, майже не захищає від радіації |
| Вікно | пропускає світло і радіацію |
| Дріт | передає енергію між модулями |

## Модулі
| Модуль | Що робить |
|---|---|
| Сонячна панель | енергія, лише вдень і під відкритим небом без пилу |
| Батарея | запас енергії |
| Kilopower (реальний проєкт NASA) | стабільна енергія, але дорогий |
| Електролізер | вода + енергія → O₂ |
| MOXIE (реальний прилад Perseverance) | CO₂ + енергія → O₂, тільки на Марсі |
| Теплиця | світло + вода + CO₂ → O₂ + їжа |
| Нагрівач | топить лід, гріє модуль уночі |
| Наукова станція | їсть енергію, дає ⭐ (мета місії) |
| Укриття | захищене місце, куди тікає екіпаж під час вспишки |

## Загрози як частинки
- Сонячна вспишка (SEP): потік частинок зверху. У кожній клітинці частинка може застрягти з імовірністю, що залежить від щільності матеріалу. Вода і камінь зупиняють краще, стіна слабко.
- Космічні промені (фон): поодинокі частинки весь час, повільно додають дозу.
- Пилова буря (Марс), мікрометеорит (пробиває дірку) — кандидати.

## Observations
- [decision] Правила матеріалів описуються даними (таблиця), щоб кілька агентів могли додавати матеріали паралельно.
- [fact] Прототип уже показує: реголіт, воду, стіну, кисень, панелі, генератор O₂, екіпаж, вспишку з поглинанням.
- [question] Чи може реголіт падати всередину модуля, якщо зламати дах? Чи руйнуються стіни?
- [question] Чи потрібна температура як окрема симуляція, чи вистачить «нагрівач їсть енергію вночі»? Пропозиція: без температури.
