# Game screen

```
☀️                          ·  ·  ← частинки радіації (вспишка)
  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓               ← шар реголіту-щита
  █ 🧑‍🚀  ░O₂░  🌱 █  ▤▤▤▤      ← модуль, кисень, теплиця | сонячні панелі
  █▀▀▀▀▀▀▀▀▀▀▀▀▀▀█━━━━━━━       ← стіна, дроти
▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒   ← реголіт
▒▒▒▒▒░░❄❄❄░░▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒   ← підземний лід
```

## Елементи
- **HUD зверху:** ⚡ енергія, 🫁 кисень, ☢️ доза, ⭐ наука, сол і день/ніч, пауза та швидкість.
- **Панель зліва:** великі іконки матеріалів і модулів, гумка (копати).
- **CAPCOM знизу:** персонаж Центру управління. Підказує, попереджає, пояснює.
- **Шари перегляду («рентген»):** радіація, енергомережа, кисень. Показують невидиму науку.
- **🔍 «Що це?»:** тапнув по пікселю й отримав коротке пояснення та факт від NASA.

## Observations
- [decision] Керування підходить і для миші, і для пальця. Цільові пристрої: ноутбук і планшет у горизонтальному положенні.
- [decision] Пауза доступна завжди: дітям треба встигати подумати.
- [idea] Екран «Джерела даних» генерується зі знімків JSON (див. скіл `nasa-data`).
